# 核验数据

`句子去哪找_11套卷核验.md` 用到的逐句数据。

- `作文逐句出处.tsv`：参考范文、高分卷全文和提纲里的每一句，标了角色，以及出自题干、出自材料哪一则第几段第几句，还是没有明确出处。用制表符分隔，Excel 和 WPS 可以直接打开。
  - **角色：** 标题、开头、论点、道理、总括、例子、收尾、结尾、对策。正文段中间的句子是人工定的，其余按位置定。
  - **段位：** 材料一二、第一段、最后一段、中间段、只有一段。
  - **段内：** 首句、末句、中间、独句，指这句在它那一段里的位置。
  - **出处：** 只列强匹配，即重合至少 8 个字、且至少两处独有的四字串；弱匹配一律记"无明确出处"。
