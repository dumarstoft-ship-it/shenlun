# 论点句名词表

论点句 = 这一面 ＋ 怎么起作用 ＋ 对题干 B 的判断。这张表只管"判断"那一半，也就是后半句用哪个名词。"这一面"和"怎么起作用"从材料和道理库里来。

**怎么查**：先写这段的道理句，看它在说什么（下表第一列），再挑名词。比如道理句是"生态环境没有替代品，失去了难以挽回"，说的是"没它不行"，查"托"那一行，论点句就是"生态美，是广东长远发展的本钱"。

**别被它卡住**，按顺序有三条退路：

1. 材料里有现成的判断句，把落点换成题干的词就用，最快。
2. 没有现成的，再查这张表。
3. 还想不出，用最简式"A 能够＋动词＋B"。2026 县镇卷 89.5 分那篇就是这么写的："推进绿美广东生态建设能够增进民生福祉。"

**背不背**：只记打 ★ 的 15 个，其余练习时翻。每天 10 分钟练习时用，练一周后看哪些真用上了，用上的留下，一次没用上的就不用管。

引文规矩同《大词卡》：「」里的字和原文逐字一致。【】是 `04_文件原文/` 的文件编号和行号，比如【01 行67】；真题材料写成【2026县镇卷 行223】，指 `03_真题/文本/` 里的文本；（）里是作文出处，可以去 `05_做题复盘/大作文逐句品读/` 或答案文件里查。

## 一页：按"这段的道理在说什么"挑

| 这段的道理在说 | 类 | 名词（★ 先记这些） | 常配的动词 |
|---|---|---|---|
| 它推着往前走 | 推 | ★动力（动能、活力）、★引擎、源泉、牵引 | 注入、增添、激发、点燃；发挥……牵引作用 |
| 没它不行，在下面撑着 | 托 | ★根基（基础、地基）、★底色、★支撑、本钱、命脉、土壤 | 夯实、筑牢、奠定、厚植 |
| 它挡住风险、稳住大局 | 护 | ★保障、★屏障、★压舱石、稳定器、底线 | 提供、构建、筑牢、守住 |
| 它是为了人 | 引 | ★落脚点（出发点）、根本目的 | 是……的出发点和落脚点；体现 |
| 它卡在要害上 | 卡 | ★关键（核心）、★抓手（着力点、突破口）、必由之路、治本之策、补短板 | 抓住、以……为……、补齐 |
| 它打开新地方 | 拓 | ★空间、新赛道（增长点）、增长极、潜力板 | 拓展、开辟、培育、打造 |
| 它把两头接起来 | 连 | ★通道（渠道）、★纽带、枢纽 | 畅通、打通、当好；发挥……纽带作用 |
| 它先走一步 | 先 | 排头兵、先行地、实验区（只给广东）；试验田、示范区 | 当好、打造 |
| 它是干这件事的主力 | 干 | ★主体、主力军、生力军 | 强化……主体地位；是……的主力军 |
| 它变成风气、名声、精神 | 软 | 风尚、精神底色、名片、软实力 | 形成、涵养、擦亮、提升 |
| 它本来就是 B 该有的（少用） | 本 | 内在要求、必然要求、应有之义；体现 | 是；体现 |

一段一类，四段尽量挑四个不同的类。这样四句读下来是四种作用，而不是同一种作用说了四遍。

## 逐个词：给谁用、要注意什么

每个词下面写三样：常见主语，也就是什么样的 A 用它顺；要注意的地方；一句例句。

### 推：它推着往前走

- **★动力（动能、活力）**
  - 主语：创新、改革、开放、产业、消费。
  - 注意：带机制，后面的道理句要说清它靠什么推。"第一动力"只能给创新，见固定提法。
  - 例：「产业强，为长远发展增添绿色动力。」（2026 县镇参考范文）
- **★引擎**
  - 主语：会动的大块头，比如城市群、大湾区、人工智能、主导产业。不给民生、生态用。
  - 例：「产业强海，是海上新广东的蓝色引擎。」（2025 选调参考范文）
- **源泉**
  - 主语：实体经济、人民。
  - 注意：语气重，多跟在文件原话后面用。
  - 例：「实体经济是一国经济的立身之本，是财富创造的根本源泉」【N19 行28】
- **牵引**
  - 主语：带全局的大工程。
  - 注意：意思是在前面拉着整体走，多写成"战略牵引""以……为牵引"。
  - 例：「绿美广东生态建设是广东生态文明建设的战略牵引」【M01 行13】

### 托：没它不行，在下面撑着

- **★根基（基础、地基）**
  - 主语：基础研究、制造业、实体经济、生态。
  - 注意：带机制，地基不牢，上面全塌。
  - 例：「基础研究是高水平科技自立自强的地基，地基打得牢，大厦才能建得高。」（2024 一卷参考范文）
  - 例：「质量强省，夯实制造业当家的基础。」（2023 参考范文）
- **★底色**
  - 主语：绿色、理念、精神。
  - 注意：底色是每一块都带着它，不是其中一块。"鲜明底色"在中央和省委文件里专说「绿色发展是中国式现代化的鲜明底色」【04 行183】，别挪给别的主语。
  - 例：「生态美，为长远发展厚植绿色底色。」（2026 县镇参考范文）
- **★支撑**
  - 主语：教育科技人才、实体经济、基础设施。
  - 注意："基础性、战略性支撑"是固定说法，只给教育、科技、人才。
  - 例：「教育、科技、人才是中国式现代化的基础性、战略性支撑。」【19 行81】
- **本钱**
  - 主语：实体经济、生态环境。
  - 注意：偏口语，材料里有就用。
  - 例：「实体经济是我国发展的本钱」【N19 行40】
  - 例：「良好的生态环境，是广东永续发展的最大本钱。」【2026县镇卷 行223】
- **命脉**
  - 主语：只给工业、制造业、关键核心技术。
  - 注意：语气很重。"国民经济命脉"是讲国有资本布局的固定说法，别借。
  - 例：「关键核心技术是高水平科技自立自强的命脉，命脉要牢牢掌握在自己手中。」（2024 一卷参考范文）
- **土壤**
  - 主语：营商环境、制度、文化这类软环境。
  - 注意：文件里"土壤"多半是字面意思（土壤污染），当比喻用只在作文里见过。
  - 例：「有为政府，厚植制造业当家的土壤。」（2023 参考范文）

### 护：它挡住风险、稳住大局

- **★保障**
  - 主语：法治、公共服务、安全、制度。
  - 注意："根本保证"只能给党的领导，不是"保障"。
  - 例：「公共服务下乡，夯实高质量发展的基本保障。」（2024 二卷参考范文）
- **★屏障**
  - 主语：生态、国家安全。
  - 例：「绿色发展是解决生态问题的治本之策，为高质量发展构建生态安全屏障。」（2026 省市 84.5 分）
- **★压舱石**
  - 主语：实体经济、制造业、产业集群这类大块头。
  - 注意：意思是风浪来了它稳得住。
  - 例：「集群聚力，打造制造业当家的压舱石。」（2023 参考范文）
  - 例：「更好筑牢实体经济“压舱石”」【N43 行16】
- **稳定器**
  - 主语：三农、社会保障。
  - 例：「要更好发挥社会保障的社会稳定器作用」【N21 行40】
- **底线**
  - 主语：安全、民生、生态。
  - 注意：写成"守住……底线"，不写"A 是 B 的底线"。
  - 例：「牢牢守住城市安全底线」【01 行163】

### 引：它是为了人

- **★落脚点（出发点）**
  - 主语：人民、民生。
  - 注意：固定说法是「实现人民对美好生活的向往是中国式现代化的出发点和落脚点」【04 行163】。不要给产业、工程用，产业不是目的。
- **根本目的**
  - 注意：用"体现"去接，不写"A 是 B 的根本目的"，因为 A 多半是手段。
  - 例：「绿色发展是满足人民日益增长的生态美好需要的必然要求，体现了高质量发展的根本目的。」（2026 省市 84.5 分）

### 卡：它卡在要害上

- **★关键（核心）**
  - 主语：材料或题干说它"关键"的那一面。
  - 注意：只表示要害，后面的道理句必须说清为什么是它卡着别的。
  - 例：「强村富民，抓住高质量发展的关键。」（2024 二卷参考范文）
- **★抓手（着力点、突破口）**
  - 主语：具体的工程、平台、政策。
  - 注意：带机制，从这里使劲能撬动全局。
  - 例：「坚持以战略为先导、政策为抓手、法治为保障、风险防控为落脚点」【04 行199】。这一句里先导、抓手、保障、落脚点四个角色分得很清楚，可以当样子看。
  - 例：「坚持把发展经济的着力点放在实体经济上」【04 行61】
  - 例：「以深中一体化为突破口」【01 行85】
- **必由之路（根本出路）**
  - 注意：说得很重，题干或材料这么说才用。"根本出路"在广东专说高质量发展。
  - 例：「这是广东的必由之路、光明大道」【L06 行12】
- **治本之策**
  - 注意：带机制，治根不治标。
  - 例：「广东坚持把绿色发展作为解决生态环境问题的治本之策」【2026省市卷 行175】
- **补短板（锻造长板）**
  - 注意：带机制，最弱的那块决定整体。"把短板变为潜力板"是百千万、县域的固定说法。
  - 例：「加快构建区域发展格局，为广东高质量发展补齐短板。」（2021 参考范文）
  - 例：「把短板变为潜力板」【02 行147】

### 拓：它打开新地方

- **★空间**
  - 主语：县域、海洋、开放、改革。
  - 例：「产业兴县，拓展高质量发展的空间。」（2024 二卷参考范文）
- **新赛道（增长点）**
  - 主语：新兴产业、未来产业、新消费。
  - 例：「形成一批投资热点和新增长点」【01 行91】
  - 例：「强化新赛道新领域制度供给」【01 行133】
- **增长极**
  - 主语：城市群、重点区域。
  - 例：「发挥重点区域增长极作用」【04 行137】
- **潜力板**
  - 主语：县域。见上面的补短板。

### 连：它把两头接起来

- **★通道（渠道）**
  - 主语：要素流动、人才交流、开放。
  - 例：「要素流动，畅通高质量发展的渠道。」（2024 二卷参考范文）
  - 例：「开放活海，是海上新广东融入世界的大通道。」（2025 选调参考范文）
- **★纽带**
  - 主语：文化、侨、宗亲、水系。
  - 例：「发挥宗亲乡亲、祖地文化等纽带作用」【05 行1139】
- **枢纽**
  - 主语：港口、大湾区、合作区。
  - 例：「当好国家高水平对外开放门户枢纽」【01 行141】

### 先：它先走一步

- **排头兵、先行地、实验区**
  - 主语：只给广东，三个连用是固定说法。
  - 注意：多放在开头定位，少放在论点句。
  - 例：「努力在新征程上当好排头兵、先行地、实验区」【01 行67】
- **试验田（示范区）**
  - 主语：深圳、横琴、前海、南沙、自贸区。
  - 例：「作为改革开放的“试验田”，深圳出台了一系列」【2025省市卷 行238】

### 干：它是干这件事的主力

- **★主体**
  - 主语：企业（科技创新的主体）、经营主体。
  - 例：「强化企业科技创新主体地位」【01 行101】
- **主力军、生力军**
  - 主语：生力军给青年。"主力军和火车头"在广东文件里专说广东之于大湾区。
  - 例：「青年是实现中华民族伟大复兴的生力军」【N17 行90】
  - 例：「当好大湾区建设的主力军和火车头」【02 行63】

### 软：它变成风气、名声、精神

- **风尚**
  - 主语：绿色生活、文明。
  - 例：「形成绿色生产新方式和生活新风尚」【05 行1039】
- **精神底色**
  - 主语：文化、精神。
  - 例：「文化亲海，是海上新广东的精神底色。」（2025 选调参考范文）
- **名片**
  - 主语：品牌、生态、营商环境。
  - 例：「擦亮“投资中国”名片」【07 行136】
- **软实力**
  - 主语：文化。

### 本：它本来就是 B 该有的（少用）

- **内在要求、必然要求**
  - 注意：不带机制，只说归属，用了就得在道理句里补为什么。只用文件里写过的搭配，不自己造。
  - 例：「区域协调发展是中国式现代化的内在要求」【04 行137】
  - 例：「发展新质生产力是高质量发展的内在要求」【07 行64】
  - 例：「城乡融合发展是中国式现代化的必然要求」【19 行133】
- **应有之义**
  - 注意：最容易写成同义反复。「产业兴旺是产业振兴应有之义。」（2025 县镇 90 分）在逐句品读里判成了虚句。
  - 正例：「文化的繁荣兴盛是全面建设社会主义现代化的应有之义」【2022县级卷 行116】
- **体现**：写成"是……的体现""体现了……"，见上面的根本目的。

## 只表示重要的定位词：放开头，不放论点句

这几个词只说明"这件事重要、要优先抓"，不说明它怎么起作用。放在开头定位或引语里没问题；放进论点句，后半句就得写出它带动了什么，不然阅卷人一问"凭什么"，这段就空了。

| 词 | 文件里怎么用 |
|---|---|
| 牛鼻子 | 「把经济工作作为带动面上各项工作的“牛鼻子”来抓」【01 行63】；「抓住科技创新这个“牛鼻子”」【L04 行10】。意思是抓住它就能带动其他工作。用了就要写出带动了什么 |
| 重中之重 | 「把解决好“三农”问题作为全党工作重中之重」【04 行125】 |
| 头号工程 | 只给百千万工程，见固定提法 |
| 必答题 | 「建设生态文明是必须答好的必答题」【2026县镇卷 行28】 |
| 战略举措、重大国家战略 | 说政策的分量，比如大湾区建设是重大国家战略 |
| 关键一招 | 只给改革开放，见固定提法 |

## 固定提法：只能给指定的主语

这些说法是中央或省委文件定死的。主语换了，轻的是用词不准，重的是观点不正确。

| 说法 | 只给 | 原文 |
|---|---|---|
| 第一生产力、第一资源、第一动力 | 科技、人才、创新 | 「必须坚持科技是第一生产力、人才是第一资源、创新是第一动力」【N20 行50】 |
| 首要任务 | 高质量发展 | 「锚定高质量发展这一首要任务」【01 行65】 |
| 新时代的硬道理 | 高质量发展 | 「把坚持高质量发展作为新时代的硬道理」【12-2 行61】 |
| 根本出路 | 高质量发展（广东实现现代化） | 「高质量发展是广东实现现代化的根本出路」【L04 行10】 |
| 第一要务 | 发展 | 「我们党始终把发展作为执政兴国的第一要务」【L06 行7】 |
| 根本保证 | 党的全面领导 | 「坚持和加强党的全面领导是推进中国式现代化的根本保证」【04 行221】 |
| 头号工程 | 百千万工程 | 「“百千万工程”是广东推动高质量发展的头号工程」【12-2 行85】 |
| 关键一招 | 改革开放 | 「改革开放是决定中国式现代化成败的关键一招」【02 行125】 |
| 鲜明底色 | 绿色发展（之于中国式现代化） | 「绿色发展是中国式现代化的鲜明底色」【04 行183】 |
| 立身之本 | 实体经济 | 「实体经济是一国经济的立身之本」【N19 行28】 |
| 立国之本、强国之基 | 制造业 | 「制造业是国家经济命脉所系，是立国之本、强国之基」【2023县级卷 行310】 |
| 基础性、战略性支撑 | 教育、科技、人才 | 「教育、科技、人才是中国式现代化的基础性、战略性支撑」【19 行81】 |
| 出发点和落脚点 | 实现人民对美好生活的向往 | 「实现人民对美好生活的向往是中国式现代化的出发点和落脚点」【04 行163】 |
| 本质特征 | 全体人民共同富裕 | 「全体人民共同富裕是中国式现代化的本质特征」【L01 行19】 |
| 本质要求 | 全过程人民民主等，文件写了什么就是什么 | 「发展全过程人民民主是中国式现代化的本质要求」【19 行171】 |
| 最大短板 | 城乡区域发展不平衡（之于广东高质量发展） | 「城乡区域发展不平衡是广东高质量发展的最大短板」（2024 二卷材料三，总书记原话） |
| 战略要地 | 海洋 | 「海洋是高质量发展战略要地」【2025选调 行22】 |
| 排头兵、先行地、实验区 | 广东 | 「当好排头兵、先行地、实验区」【01 行67】 |
| 动力源；主力军和火车头 | 大湾区；广东之于大湾区 | 「打造高质量发展动力源。当好大湾区建设的主力军和火车头」【02 行63】 |
| 生力军 | 青年 | 「青年是实现中华民族伟大复兴的生力军」【N17 行90】 |
| 前提、保障 | 安全是发展的前提，发展是安全的保障 | 「安全是发展的前提，发展是安全的保障」【07 行70】 |
| 最大确定性、最大底气、最大保证 | "两个确立"，不要借用 | 「最大确定性、最大底气、最大保证」【12-1 行57】 |

**说重了的词**：根本、决定性、唯一、最大、首要、第一。原文这么说了才用，自己不要往上加。比如可以写"绿色发展是高质量发展的底色"，不要写"绿色发展是高质量发展的根本"。

## 历年核对：表里收了多少

从 2020—2026 年的参考范文、选调参考范文和高分卷里，一共抽出 126 句论点句（逐句品读里标了【分论点】的，加上答案文件里每段的第一句）。其中用到的表示关系的名词有 55 个，不重复计算。

**收进表里的有 42 个**，包括正表、固定提法和定位词，近义的算进同一个词：

- 推：动力、动能、活力、引擎、牵引
- 托：基础、根基、地基、底色、支撑、命脉、土壤
- 护：保障、屏障、压舱石
- 引：根本目的
- 卡：关键、核心（要素）、抓手、必由之路、治本之策、短板、长板
- 拓：空间、潜力股（按"潜力板"收）
- 连：渠道、通道
- 软：招牌（按"名片"收）、生活方式（按"风尚"收）、精神底色
- 本：内在要求、迫切要求（和"必然要求"同一类）、必然要求、应有之义、体现
- 固定提法：第一动力、第一资源、立国之本和强国之基、最大短板、战略要地
- 定位词：战略举措、重大国家战略

**没收的有 13 个，都是故意不收**：

| 词 | 为什么不收 |
|---|---|
| 新局面、新格局、增量 | 结果词，只说有了结果，不说怎么起作用 |
| 优势、基本力量、未来 | 太泛，换到哪句都通，等于没说 |
| 底气 | 文件里"最大底气"专说"两个确立"，一般的"底气"又太泛 |
| 主角 | 比喻，文件里不这么说；想用就写"主体" |
| 留量、销量、能量、力量（同一组，算一个） | 文字游戏，好看但不说明作用 |
| 绿色银行 | 材料里的比喻，那道题材料有就用，别的题用不上 |
| 文化供给、良好环境 | 具体宾语，属于"并成一个动宾"的写法，不需要关系名词 |
| 画卷 | 收尾的画面词，不是判断 |

另外有些论点句根本没用关系名词，直接用动词接 B，比如"产业振兴助力乡村人才振兴""绿美广东生态建设带来生态美"。这就是最简式，照样能用。
