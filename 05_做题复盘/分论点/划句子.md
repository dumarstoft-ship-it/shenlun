# 划句子：考场上标什么、怎么标

**一句话：** 只划会用的句子。每划一处，同时记下两件事：它在作文里干什么（用哪种括号），它说的是哪一面（旁边写一个面字）。

**参照：** 本人 2026 省市卷作文。成稿和句子来源表见 [`2026/本人作答_2026省市_大作文.md`](../2026/本人作答_2026省市_大作文.md)，逐句的划法和对照见 [`核验数据/2026省市_划句子.tsv`](核验数据/2026省市_划句子.tsv)。没有用高分卷。

文中"核过"是拿这篇作文逐句对过的；只有这一篇，下一步拿 2026 县镇卷再验。

## 一、记号

| 记号 | 标什么 | 放进作文哪里 | 例（2026 省市） |
|---|---|---|---|
| ①②③④ | 开头四手的料：①引语，②道理，③广东出场，④串 | 开头 | ① 绿色发展是高质量发展的底色。（材料一）④ ……协同推进降碳、减污、扩绿、增长……（材料二） |
| { } | 论点料：能进分论点的。第三格的作用词（动力、屏障、治本之策、必然要求、关键环节……），或者第二格的做法（中央部署清单里的一项） | 分论点 | {产 绿色低碳产业……也是推动广东实现高质量发展不可或缺的新动力。}（材料四） |
| [ ] | 道理料：讲为什么。主语是别的东西，说它是什么性质（根基、系统工程、并非……而是……、牛鼻子） | 分论点后的道理句 | [生 生态环境是人类生存与发展的根基。]（材料六） |
| ( ) | 收尾料：段末、则末的判断或描写 | 段尾 | (江河湖海焕发新生机，成为广东打好污染防治攻坚战的生动注脚。)（材料六） |
| (尾) | 结尾料：总览则末段的画面句；中央要求里能当目标的那半句 | 结尾 | (尾 岭南大地青山常在，绿水长流……)（材料二末段） |
| / | 例子：第一遍读，在个案、数据之间划斜杠隔开 | 例子 | ……补上生态欠账。/ 针对突出的水污染问题……/ 在 2022 年底……92.6%…… |
| 面字 | 一个字记它属于哪一面：产、生、民、碳 | — | {产 ……}、[碳 ……] |

**面字只写在 { } [ ] 旁边。** ( ) 和 / 在哪则材料，就默认属于哪一块；要挪到别的块去用，才写面字。

**{ } 还是 [ ]，看主语：** 主语是 A（绿色发展）或者这一面，说它对 B（高质量发展）起什么作用，是 { }；主语是别的东西（生态环境、治理、投入、能源转型），说它是什么性质，是 [ ]。一句话两半都有，就两半各划。比如材料七首句：
> {民 推动绿色发展是满足人民日益增长的优美生态环境需要的必然要求，}[良好的生态环境是美好生活的基础、人民共同的期盼。]

成稿里，前半句成了民生段的分论点，后半句成了道理句。

## 二、来源 × 句式：九格里哪些划

**来源怎么认：**
- 中央：句里有"习近平""总书记""党中央""党的二十大"之类。
- 广东全省：主语是"广东""全省"，或者是省委、省政府讲的。
- 无来源：都没有。没主语的判断（"生态环境是人类生存与发展的根基"）、某市某村的个案，都算这一类。

**句式怎么认：** 是什么（判断、评价、描写），要什么（要、必须、如何……？），做了什么（做法、数据、个案）。

| 句式＼来源 | 中央 | 广东全省 | 无来源 |
|---|---|---|---|
| 是什么 | 划。3 句：划 2 句，成稿都用了 | 划，多是 ( ) 收尾备选。3 句：都是备选 | 划，{ } [ ] ( ) 大多出在这格。24 句：打括号 17 句，用了 14，备选 3 |
| 要什么 | 只划能当结尾目标的那半句，(尾)。2 句：划 1 句，用了 | 只划问句，③。1 句，用了 | 这篇没有 |
| 做了什么 | 讲成绩、历程的不划；列部署清单的划 { }，每项给一面当第二格。2 句：各 1 | 划斜杠；四种例外打括号（见下）。31 句：斜杠 16、括号 4，用了 14 | 划斜杠。25 句：斜杠 12，用了 7 |

**合成一句：是什么，说的是 A、B 或某一面的，一律划，按用途分括号；要什么只划两种；做了什么划斜杠；中央的成绩、历程不划，部署清单划 { }。**

**中央的部署清单**长这样，每一项正好能给一面当第二格（这一面干了什么），逐项标面字：
> 党的二十届四中全会通过的《中共中央关于制定国民经济和社会发展第十五个五年规划的建议》，……对"十五五"时期加快经济社会发展全面绿色转型作出战略部署，{生 持续深入推进污染防治攻坚和生态系统优化}，{碳 加快建设新型能源体系，积极稳妥推进和实现碳达峰}，{民 加快形成绿色生产生活方式}。（2026 省市材料一第 2 段首句）

本人减碳段第一稿的"积极稳妥推进"、成稿的"推进碳达峰碳中和"里的"推进"，都出自这一句。

"是什么"那一条带一个语义条件：说的得是题干的 A、B 或者本块那一面。对党中央的称颂（"这充分彰显了……坚强意志和坚定决心"）、活动的背景（"'绿色'排在第一位"），句式是"是什么"，说的却不是 A、B，不划。

**"做了什么"打括号的四种例外：**
1. 总览则里的那一串做法，划 ④：广东……协同推进降碳、减污、扩绿、增长……（材料二）
2. 挑战句，划 ③：工业规模占全国八分之一的同时，广东也曾面临土地开发强度高、环境承载力逼近极限的挑战。（材料四）
3. 句里带作用词的，划 { }：{生 广东坚持把绿色发展作为解决生态环境问题的治本之策……构建可持续发展的绿色生态安全屏障。}（材料六首句）
4. 一则材料的最后一句，划 ( )：(各地以绿美点建设为牵引，带动绿美广东生态建设向纵深开展，……惠及千家万户。)（材料七末句）

## 三、不划的七种

1. **背景句**：时间、会议、活动的介绍。"第十五届全国运动会于 11 月 9 日至 21 日在广东、香港、澳门举行。""此外，这届全运会也将'无废全运'理念贯穿办赛前后。"
2. **中央讲成绩、历程的，以及对它的称颂**："党的十八大以来，以习近平同志为核心的党中央……形成了习近平生态文明思想""这充分彰显了……"。中央列部署清单的不在此列，见第二节。
3. **中央要求里当不了结尾目标的**："一定要真正重视起来，采取真正有效的举措加强保护。"
4. **总览则里的数据段**：材料二"2024 年，广东……"那三段，一共 11 句。第一遍不划，哪块例子不够再回来找。
5. **个案中间的细节**：一个个案只在头尾划斜杠，中间的过程、场景、人物的话不划，比如"漫步其中，郁郁葱葱，不时听见鸟鸣。"
6. **不贴本块那一面的**：茶山片区讲的是文旅产业，在民生块里不划；"无废全运"讲的是减废，"理念""风尚"讲的是生活方式，在减碳块里都不划。
7. **小题材料**：整则不划，只看末段的判断句。材料三末段"H 电子的实践证明，……绿色低碳投入并非成本负担，而是竞争力的源泉"，划 [产]。

**核过：** 按这七条，2026 省市 90 句（不算两则小题材料）里不划 33 句，成稿一句都没用到它们。

## 五、形和义怎么一起练

划一个记号，要同时答出两件事：
- **它在作文里干什么**：选哪种括号。论点料还是道理料，读懂了才分得出：说 A 对 B 起什么作用的是 { }，讲为什么的是 [ ]。
- **它说的是哪一面**：写哪个面字，贴不贴本块的面。不读懂写不出来。

所以这套记号本身把形和义绑在了一起：光认句式，画不出括号；光懂意思，也画不出括号。像算式一样，括号是这一步的运算，面字是这一步算出来的意思，两样一起落笔。

**练法：**
1. 每次拿一则材料，逐句落记号（①②③④、{ }、[ ]、( )、(尾)、/、不划），{ } [ ] 带面字。限时，每句五秒。
2. 对答案：拿写过的那篇作文反推，像上面这张表。
3. 错的分两类记：形错（句式、位置认错了），义错（面认错了，贴不贴面判错了）。哪类多就盯哪类。
4. 练到不用分步想：看到句子，记号自己出来。
