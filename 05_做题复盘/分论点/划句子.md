# 划句子：读的时候划什么，拼的时候去哪找

**一句话：** 读的时候，一句读完问两件事：读完脑子里多了什么，好不好看。拼的时候，看到就用，记得就用；找不到看附近；附近也没有，翻开头。

这一版是「人用版」：规矩只留考场上凭感觉容易漏的几条，具体挑哪一句凭感觉。两个候选都合格时挑哪个，不影响分数，不值得为它立规矩。旧版按「来源 × 句式」九格判的那一套，在 git 历史里；`划句子_逐格.md` 是旧版的逐格细看。

---

## 一、读的时候划

| 记号 | 什么时候划 | 先往哪放 |
|---|---|---|
| { } | 读完多了一个道理；宽的「做了什么」（没有数字、地名、个案）也算 | 论点、道理 |
| / | 读完多了一件具体的事：带数、带地名、带项目 | 例子 |
| ★ | 加在 { } 或 / 上：又好看又有料。/★ 只标数字亮眼的事 | 显眼的地方：标题、论点、开头、结尾；能架几面就当架子 |
| ( ) | 没多什么，但好听，说的是一面 | 段尾回扣 |
| (尾) | 没多什么，但好听，说的是整个广东或更大 | 标题、开头、结尾 |
| ③ | 广东干得好的、干得不好的、成效、要答的题 | 开头「对广东而言」 |
| ① ④ | 总书记原话；材料给的一串做法 | 开头的引语；开头的「做什么」 |
| 面字 | 旁边写一个字，记它属于哪一面 | — |
| 不划 | 没多什么也不好听；或者太碎（个案中间的细节） | — |

例：
- {★} 产业兴则经济兴，产业强则国家强。（2025 省市材料六）
- { } 广东向"高"攀登，在战略必争领域并跑领跑。（2025 省市材料三，宽的「做了什么」）
- /★ 全国每 3 台工业机器人就有一台"广东造"。（2025 省市材料六）
- ( ) 江河湖海焕发新生机。（2026 省市材料六）
- (尾) 岭南春来早，人勤地生宝。（2025 省市材料一）

**「好看」认长相：** 对仗或同一句式重复、比喻（牛鼻子、底色）、并非……而是……、不仅……更……、诗句俗语、画面。

**按分句判：** 长句的尾巴上常挂着好用的半句，一句话的两半可以各划各的。

**只说一个个案的好听话**（比如「漫步其中……」），不另划，跟着例子走。

**拿不准就划 { }：** 正文没用上，结尾还能用。

## 二、拼的时候：每个位置要什么

- **格子：** 材料里一定给了，要么一句话列全，要么一块材料一格。拿例子去嵌，每组例子都有地方放、不用硬塞的那套就是。
- **标题：** 短的 ★ 或 (尾)；没有就用题干关键词。
- **开头：** 引语（①）→ 道理句（{ }，有就用）→ 对广东而言（③：过、未、令）→ 做什么（④，或者把格子词连起来）→ 论点句（题干原句加「正」；题干是一件要做的事，先改成判断句）。
- **中间每段：**
  - 论点：两半句，做什么、是什么随便配，面字放在前半句；料是 { }，比较宽、有信息。
  - 道理：{ } 里讲「是什么」的，比较宽；有就用，没有就省。
  - 例子：/，广东做了什么，比较窄；跟着本段走，两个就够，各留一个数。
  - 回扣：( ) 里广东做成了什么，再扣回论点；附近没有 ( )，就把论点改成「正……」。
- **结尾：** 起（没什么信息量但热血的诗句，或者没用上的道理句、★）→ 回收开头（开头说广东要干什么，结尾说「唯有……才能……」）→ 落（(尾) 里没什么信息量、但很漂亮的句子）。

---

## 三、去哪找

看到就用，记得就用，不管它在哪一块。找不到，看附近；附近也没有，翻开头（材料一、二）。跳得太远的不用。

广东的事读的时候已经打了序号，开头要用时直接挑。

---

## 四、四条提醒

凭感觉容易漏的，只有这四条：

1. 好看的句子先往显眼的地方放：标题、论点、开头、结尾。别都攒到结尾。
2. 扫一眼有没有能架几面的句式（比如「××因产业而×」），有就用，没有就算。
3. 题干有两头的（比如长远发展、民生福祉），论点后半记得带上。
4. 最后还没用上的 ★，放进开头的道理句或结尾的起句。

---

## 五、基本改法

不背句式，只用这几种改法：

1. **去壳：** 广东坚持把绿色发展作为解决生态环境问题的治本之策 → 绿色发展是解决生态环境问题的治本之策。
2. **换主语：** 广东向"高"攀登 → 科技创新向"高"攀登。
3. **缩句：** 一个个案只留一件事、一个数。
4. **问句改陈述：** 如何将短板变为潜力板？→ 要把短板变为潜力板，广东必须……
5. **已然改进行时（回扣用）：** ……惠民富民的成色才会更加动人 → ……成色更加动人，……越来越……
6. **题干加「正」：** 乡村振兴关键在产业振兴 → 乡村振兴的关键，正在于产业振兴。

连接只用「对广东而言」「近年来」「如今」这一类。不套「以……为……，让……」这种现成句式，也不自己造比喻、排比。
