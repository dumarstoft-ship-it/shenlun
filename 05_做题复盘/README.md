# 05_做题复盘

先按 2023 → 2024 → 2025 → 2026 顺序做 9 套省考，再做 2024、2025 两套选调。每套先自己作答、再对参考答案和高分卷，逐年修订方向；最后用 55 份真人得分卷核验，得到最终版 v7。

- **先看这个 →** [`备考方向_总结.md`](备考方向_总结.md)（最终方向 v7 + 练习安排）
- `分论点/`：大作文分论点怎么写。方法论一份，四关练习一份，答案单独一份，做完练习再看答案
  - `分论点/句子去哪找_11套卷核验.md`：写作文时句子去哪找，拿 11 套卷核验第十节的规则，附原理和改法
  - `分论点/缓冲区.md`：还没在卷子上试够的写法，先放这里，试过好用再并进方法论
- `2023/`：县级卷、乡镇卷作答 + 复盘（方向 v1）
- `2024/`：一卷、二卷、三卷（行政执法）作答 + 复盘（方向 v2）
- `2025/`：省市卷、县镇卷作答 + 复盘（方向 v3）
- `2026/`：省市卷、县镇卷作答 + 复盘（方向 v4；本年无官方参考答案，对照高分卷合集）
  - `本人作答_2026省市_大作文.md`：本人一段一段写、和 Claude 一起改的大作文，有原稿、成稿、句子来源表和复盘。这份和上面的 `我的作答_*.md` 不同，记下了修改过程
- `选调/`：2024、2025 选调申论（方向 v5、v6）
  - 每年三份盲做：A、B 按方向作答，C 是没看方法的对照组；每份都逐点对照参考答案，并经过对抗核验
  - `方向核验_真人卷.md`：用 55 份真人得分卷逐条检验方向，以及我对核验结论的复核

每个 `我的作答_*.md` 都是**做完才看答案**的原始版本，没有事后修改。复盘里后来发现的错误，以"⚠️ 更正"的形式补记在原处，没有删改原文。

**注意**：
- 2021—2023 年的选调考的是选择题（综合能力 / 思维能力测试），没有申论。
- 2024 选调要用 `24广东选调《申论》答案.pdf` 后附的材料，题目 PDF 里的那版是拼错的。
