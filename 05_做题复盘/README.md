# 05_做题复盘

先按 2023 → 2024 → 2025 → 2026 顺序做 9 套省考，再做 2024、2025 两套选调。每套先自己作答、再对参考答案和高分卷，逐年修订方向；最后用 55 份真人得分卷核验，得到最终版 v7。

- **先看这个 →** [`备考方向_总结.md`](备考方向_总结.md)（最终方向 v7 + 练习安排）
- `分论点/`：大作文分论点怎么写。方法论一份，四关练习一份，答案单独一份，做完练习再看答案
  - `分论点/句子去哪找_11套卷核验.md`：写作文时句子去哪找，拿 11 套卷核验第十节的规则，附原理和改法
  - `分论点/开头写法.md`：关系论证题从引语一路写到结尾：开头五手、第 3 手七条线怎么选、正文和结尾怎么跟着咬合，每一手都有为什么和误用
  - `分论点/开头写法_接口例子.md`：上面那份里"接口检查"的 14 条逐条例子，每条有原来、卡在哪、改成、为什么通
  - `分论点/划句子.md`：人用版。读的时候一句读完问两件事（读完多了什么、好不好看），划 { } / ( ) (尾)，又好看又有料加 ★，广东的事打序号；拼的时候每个位置要什么，句子看到就用、记得就用、找不到看附近再翻开头；四条提醒和六种基本改法
  - `分论点/划句子_逐格.md`：旧版「来源 × 句式」九格的逐格细看，已被上面的人用版替代，留作参考
  - `分论点/缓冲区.md`：还没在卷子上试够的写法，先放这里，试过好用再并进方法论
- `考场推演_2024-2026_大作文.html`：八套大作文合在一页的考场推演，浏览器直接打开。八套是 2024 一卷、二卷、选调，2025 省市、县镇、选调，2026 省市、县镇；2026 省市是本人作答，其余七篇按方法拼。开头是总览，有三块：一是两条心法（分论点格子材料里一定给了，拿例子去嵌；论点句两半句）在八套卷子上对一遍；二是方法冲突按类归堆；三是参考范文从材料里拿的句子，当时划没划。年份文件夹和 `选调/` 里有单卷版
- `2023/`：县级卷、乡镇卷作答 + 复盘（方向 v1）
- `2024/`：一卷、二卷、三卷（行政执法）作答 + 复盘（方向 v2）
  - `考场推演_2024一卷_大作文.html`、`考场推演_2024二卷_大作文.html`：单卷版考场推演，成稿按方法拼，不是本人作答
- `2025/`：省市卷、县镇卷作答 + 复盘（方向 v3）
  - `考场推演_2025省市_大作文.html`、`考场推演_2025县镇_大作文.html`：单卷版考场推演，成稿按方法拼，不是本人作答
- `2026/`：省市卷、县镇卷作答 + 复盘（方向 v4；本年无官方参考答案，对照高分卷合集）
  - `本人作答_2026省市_大作文.md`：本人一段一段写、和 Claude 一起改的大作文，有原稿、成稿、句子来源表和复盘。这份和上面的 `我的作答_*.md` 不同，记下了修改过程
  - `考场推演_2026省市_大作文.html`：上面那篇按考场顺序重走一遍的网页，浏览器直接打开。共六步：读题、划句子、找格子、拼文章、誊稿纸、对答案。材料按"读完多了什么＋句式"逐句判，每句能点开看为什么这么划、后来用在哪；成稿 23 句逐句对回出处
  - `考场推演_2026县镇_大作文.html`：县镇卷的单卷版，成稿按方法拼，不是本人作答
- `选调/`：2024、2025 选调申论（方向 v5、v6）
  - 每年三份盲做：A、B 按方向作答，C 是没看方法的对照组；每份都逐点对照参考答案，并经过对抗核验
  - `方向核验_真人卷.md`：用 55 份真人得分卷逐条检验方向，以及我对核验结论的复核
  - `考场推演_2024选调_大作文.html`、`考场推演_2025选调_大作文.html`：单卷版考场推演，成稿按方法拼，不是本人作答

每个 `我的作答_*.md` 都是**做完才看答案**的原始版本，没有事后修改。复盘里后来发现的错误，以"⚠️ 更正"的形式补记在原处，没有删改原文。

**注意**：
- 2021—2023 年的选调考的是选择题（综合能力 / 思维能力测试），没有申论。
- 2024 选调要用 `24广东选调《申论》答案.pdf` 后附的材料，题目 PDF 里的那版是拼错的。
