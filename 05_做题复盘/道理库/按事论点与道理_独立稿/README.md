# 按事论点与道理：独立稿

**交付：21份专题，另附大事清单、政策核验记录和来源索引。** 保留原00—16，新增17教育、18人口、19体育，20健康广东作为备用专题。核验截至2026-11-03。

从[大事清单](大事清单.md)进入各专题；需要复核政策事实，看[核验记录](核验记录.md)。本稿按附件要求独立研究，未读取考生已有道理卡或按事句库；沿用的是任务范围，不是旧句子。

## 先说我的判断

**提前准备句子是对的，但应记“作用链＋句子”，不能只记一个可以随意换〔B〕的句壳。** 真正可迁移的是“这一面怎样起作用”。题干的目标一变，论证距离也会改变；有时换几个字就够，有时必须补一个中间环节，有时整句就不适用。

| 已备机制 | 题干落点 | 怎样使用 |
|---|---|---|
| 专业服务→提高制造价值 | 产业高质量发展 | 可以直接衔接；例子证明服务怎样改善研发、生产或市场连接。 |
| 专业服务→提高制造价值 | 共同富裕 | 还要有就业增收、利益联结等材料，不能把产业收益自动当成群众收益。 |
| 数字技术→扩大服务触达 | 民生福祉 | 还要看群众是否用得上、负担得起；上线不等于受益。 |
| 公共文化→拓宽参与机会 | 精神生活共同富裕 | 可以沿可及性、参与和精神获得论证；换成产业增长则须另补消费转化。 |

附件总结的“面是给的”“作文永远证明一件事”“每篇都碰总纲”，本稿作为备考假设使用，没有把它们当成官方命题规则。我的处理是：**题干和材料决定本篇用哪几面，政策库帮助认出并解释这些面。** 官方文件中的拆分也可能跨层级，不能直接当成四段作文提纲。

## 每份里有什么

- 待证明命题：说明可能的证明任务，统一标预测。
- 开头两句：定性、代价；代价只点出失去的条件，不夸大现实问题。
- 主面：优先据官方结构，跨文件归纳时明说。
- 隐藏面：标明来自哪段意义、原则或新部署。
- 周边面：为材料另给的支撑面预留入口，不默认必写。
- 面间关系：每条同样配论点句、道理句、例子要证。
- 使用边界、拿不准之处、官方来源标题／日期／链接／段落定位。

所有开头句、论点句和道理句均为**自拟**，可使用官方概念，但不能冠“总书记指出”。来源记录证明拆面的根据，不证明自拟句是原话。正文个别明确标出的短原句，只用于核验出处。

## 考场怎么调出来

1. **先认任务。** 圈出题干的行动／事物〔A〕、落点〔B〕和指定关系，判断是“事的价值”“相互关系”还是“怎样实现”。
2. **再认机制。** 将材料压成“这一面→发生什么变化→如何到〔B〕”。相同关键词可能属于不同机制，不能靠词语匹配归类。
3. **选句并改句。** 从主面挑主干，材料明确给出的隐藏面可以升格；只取有材料支撑的几面，不强凑四句。
4. **用例子验句。** 检查例子是否证明道理句中的中间环节。只证明“做了什么”，就不能直接写成“所以实现了〔B〕”。

四句分论点要能分别说明四种作用。若第一句写“人才”，第二句还是人才带来的“创新活力”，要看它们是否只是同一条链的前后两环；若是，就合并或调整，而不是换名词凑段。

句子多数控制在30字以内；〔B〕填入完整题干后，必要时连介词和句尾一起改。字数服务清楚表达，不追求生硬压缩。

## 几个核验后的结构调整

1. **党建更新到五中全会与11月2日广东传达大会。** 五中全会主题是持之以恒推进全面从严治党；“十五五”规划部署不能误标为五中全会内容。详见16及核验记录。
2. **产业突出两业协同，并补10月先进制造业大会。** 不再只有泛化的“创新、人才、改革”三个万能面。
3. **百千万保留县域、县城、镇村、改革、社会参与的区别。** 义乌经验另设子卡，粮食安全与大食物观放农业子卡。
4. **教育、人口、体育各有独立机制和部署依据。** 健康广东也能独立成题，但本稿列为备用，未用未核实的大会名称抬高其优先级。
